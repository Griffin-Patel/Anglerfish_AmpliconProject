# Analysis folder

This folder contains the main R Markdown analysis files and their rendered HTML outputs for the anglerfish amplicon sequencing project.

Files:
- 01_DADA2Anglerfish.Rmd / .html
- 02_Phyloseq_PreprocessingAnglerfish.Rmd / .html
- 03_PreProcessingAnglerfish.Rmd / .html
- 04_BiodiversityAnglerfish.Rmd / .html
- 05_Community_AnalysisAnglerfish.Rmd / .html

These files document the workflow from ASV assignment through preprocessing, biodiversity analysis, and community analysis.
