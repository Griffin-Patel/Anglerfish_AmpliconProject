# Figures folder

This folder contains the figure outputs generated throughout the analysis. The figures are organized by workflow step so it is easy to see which part of the project each figure came from.

## Subfolders

- **01_QualityTrimming**  
  Figures related to sequence quality control, trimming, and filtering.

- **02_AssignASVs**  
  Figures related to ASV assignment, denoising, merging, and chimera removal.

- **03_PreProcessing**  
  Figures related to preprocessing, phyloseq setup, and filtering decisions.

- **04_Biodiversity**  
  Figures related to Hill numbers, rarefaction, and alpha diversity analyses.

- **05_Ordination**  
  Figures related to beta diversity, ordination, PERMANOVA, and dispersion testing.

- **06_Composition**  
  Figures related to taxonomic composition at the phylum, genus, and ASV levels.

## Notes

These figures are the main visual outputs used to interpret how microbial communities differ between luminous and non-luminous anglerfish tissues.
