# Code folder

This folder contains helper code used across the project.

## Files

- **colors_and_shapes.R**  
  This file contains plotting colors, shapes, and other aesthetic settings used to keep the figures consistent across the project.

- **functions.R**  
  This file contains helper functions used in preprocessing, plotting, or other repeated analysis steps.

## Notes

These files help keep the main analysis scripts cleaner and make repeated code easier to manage.
